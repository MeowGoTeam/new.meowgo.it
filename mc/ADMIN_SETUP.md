# Area segnalazioni

La pagina è volutamente senza Firebase Authentication e si trova a:

`/mc/joefsdvn.html`

**ATTENZIONE:** il nome casuale dell'HTML non è una protezione reale. Con `.read: true` nel Realtime Database, chiunque conosca o scopra il database può leggere le segnalazioni. Questa modalità va usata solo se accetti che le segnalazioni non siano realmente private.

La pagina è in sola lettura: non modifica né cancella le segnalazioni.
